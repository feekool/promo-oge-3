Установка: 5 шагов

Даже без опыта в программировании. Проверено на реальных курсах ОГЭ.

1

GitHub аккаунт

Зарегистрируйся на github.com — бесплатно, можно через школьную почту

2

Открой шаблон

Перейди на github.com/feekool/feekool.github.io и нажми «Use this template»

3

Создай репозиторий

Назови его, например, oge-math-2026 или oge-russian-tutor — как удобно

4

Включи GitHub Pages

Settings → Pages → Source: main branch → Save. Жди ~60 секунд

5

Готово 🎉

Твой форум доступен по ссылке вида https://твое-имя.github.io/oge-math-2026. Начинай наполнять!

Вопросы и ответы

Если не нашёл ответ — напиши в Issues

Нужно ли знать программирование? +
Нет. Базовая установка — 5 кликов в интерфейсе GitHub. Если хочешь кастомизировать дизайн — пригодятся основы HTML/CSS, но это опционально.
Можно ли использовать для платных курсов? +
Да. Feekool — инструмент, а не сервис. Ты сам решаешь, как монетизировать контент. Некоторые репетиторы делают публичное демо + приватный раздел для оплативших.
Что если я хочу сменить предмет? +
Создай новый репозиторий из того же шаблона — это займёт 2 минуты. Или склонируй существующий форум и замени контент. Всё под твоим контролем.
Как обновлять шаблон? +
Через GitHub: добавь upstream-репозиторий, сделай git pull и разреши конфликты при необходимости. Или используй кнопку «Sync fork» в интерфейсе.
А если я не хочу использовать GitHub? +
Шаблон — это просто статический HTML/CSS/JS. Его можно загрузить на любой хостинг: Netlify, Vercel, ваш сервер. GitHub Pages — просто самый простой вариант.
